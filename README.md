# Siamand Shirzad — Portfolio

Personal portfolio of **Siamand Shirzad**, a front-end developer focused on React, Tailwind CSS, and motion-rich interfaces.

Live site: [siamandshirzad.ir](https://siamandshirzad.ir) · GitHub Pages: [siamand-shirzad.github.io](https://siamand-shirzad.github.io)

## Features

- Home with hero, about, and services
- Featured projects with live demo and GitHub links
- Contact form (Formik + Yup)
- Dark glass UI, particles, and Framer Motion / GSAP animations
- Responsive navbar and mobile project cards

## Tech stack

- React 19 + Vite 7
- Tailwind CSS 4
- React Router
- Framer Motion, GSAP
- Formik, Yup
- Zustand, Redux Toolkit
- Lucide / React Icons

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
